Abstract: A new motion-encoded Particle Swarm Optimization (MPSO) algorithm is proposed for the detection of UAV (Unmanned Aerial Vehicle) moving targets. Starting from Bayesian theory, the search problem can be transformed into an optimization problem of a cost function representing the probability of target detection. Here, the suggested MPSO development aims to address this issue by encoding the search trajectory as a series of evolving particle paths in the Particle Swarm Optimization algorithm. This motion-encoded method allows for the preservation of important attributes of the population, including cognitive and social cohesion, thereby producing better solutions. Experimental results show that the detection performance of the algorithm improved by 24% compared to the original Particle Swarm Optimization algorithm, with a time performance improvement of 4.71 times, and outperforming other algorithms such as Artificial Bee Colony (ABC), Ant Colony Optimization (ACO), Genetic Algorithm (GA), Differential Evolution (DE), and Tree Seedling Algorithm (TSA) in most search scenarios. Through experiments on searching dynamic targets under different scenarios for real UAVs, the superiority of the MPSO algorithm in practical applications is verified.

Principles: The search problem is formulated by modeling the target, sensors, and confidence map. Details are as follows.
2.1. Target Model
In the search problem, the target is described by an unknown variable x ∈ X, which represents the position of the target. Before the start of the search, a probability distribution function (PDF) is used to model the target's position based on available information, such as the last known position before signal loss. The PDF can be a normal distribution centered around the last known position, but it can also be a uniform PDF if the target's position is unknown. In the search space, this PDF is represented by a grid called the confidence map b(x0), where the value in each cell corresponds to the probability that the target is in that cell. A mapping can be created by discretizing the search space S into cells of size Sr × Sc and assigning probabilities to each cell. Assuming the target exists in the search space, we have ∑ x0∈S B(x0) = 1.
During the search process, the target may not be stationary but rather navigate in a certain pattern. This pattern can be modeled as a stochastic process, which can be assumed to be a Markov process. In special cases where the deterministic nature of the target is determined, this is considered in this study, where the pattern depends solely on the initial position x0 of the target. In such cases, the transition function p(xt| xt−1), representing the probability that the target moves from unit xt−1 to xt, is known for all units xt ∈ S. Therefore, if the initial position of the target is known, then the path of the target will be completely known. This assumption is often used in sea survivor search [24] and general search problems [5].
